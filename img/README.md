# Recursos visuais

Adicionar aqui o logotipo e as capturas reais da interface do Focus Clínica quando estiverem disponíveis.

- Usar nomes descritivos, como `calendario-focus-clinica.webp`.
- Registrar a origem e a autorização de uso quando necessário.
- Evitar dados pessoais nas capturas.
- Conferir resolução, tamanho e legibilidade antes de usar na página.
- Definir texto alternativo coerente com a função de cada imagem.

Nenhuma captura real foi adicionada nesta etapa. Não usar imagens geradas ou ilustrações como se fossem capturas do produto.
