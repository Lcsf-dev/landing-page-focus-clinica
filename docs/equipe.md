## Para quem ficará com API e testes

É possível testar uma implementação realizada por outra pessoa. O responsável deve:

1. Clonar o repositório e executar conforme o README.
2. Participar da escolha da API e documentar os dados necessários.
3. Combinar com o responsável pela interface os elementos e estados usados pela integração.
4. Implementar a integração se essa for a divisão acordada; essa parte está reservada.
5. Testar sucesso, carregamento, falha de rede, erro HTTP e ausência de dados.
6. Testar também navegação, dispositivos e interações.
7. Registrar resultado real, ambiente, evidência e problema encontrado.
8. Abrir Issues e, se acordado, corrigir problemas em branches próprias.
